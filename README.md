# CRUD Application with Next.js

A **CRUD (Create, Read, Update, Delete) web application** built with the **Next.js App Router** and **Supabase**. This project demonstrates how to leverage Server Components for fast data fetching and Server Actions for secure database mutations without creating manual API routes.
Also has a cryptocurrency portfolio tracker and analytics dashboard for registered users.

[Demo](https://crud-next-app-vladnew91.vercel.app/)

## Key Features

- **Secure Authentication**
  - User signup and login via Supabase Auth.
  - One-click OAuth social login with **GitHub**.
- **Interactive Dashboard**
  - Full **CRUD** operations (Create, Read, Update, Delete).
  - **Bitcoin History Chart:** Dynamic and responsive historical price chart powered by Recharts.
  - **Live Market Data:** Real-time price tracking for the most popular cryptocurrencies.
- **Modern Tech Stack**
  - High-performance rendering and routing via Next.js.
  - Secure data storage and instant backend APIs with Supabase.

## Tech Stack

- [Next.js](https://nextjs.org/docs)
