# CRUD Application with Next.js

A production-ready **CRUD (Create, Read, Update, Delete) web application** built with the **Next.js App Router** and **Supabase**. This project demonstrates how to leverage Server Components for fast data fetching and Server Actions for secure database mutations without creating manual API routes.

[Demo](https://crud-next-app-vladnew91.vercel.app/)

## Key Features

- **Complete CRUD**: Create, read, update, and delete database records seamlessly.
- **Next.js Server Actions**: Secure, server-side data mutations directly from interactive forms.
- **Supabase PostgreSQL**: Scalable and relational cloud database architecture.
- **Real-time Revalidation**: Immediate UI updates using Next.js caching and `revalidatePath`.
- **Modern UI Layout**: Responsive and accessible design built with Tailwind CSS.

## Tech Stack

- [Next.js (App Router, TypeScript)](https://nextjs.org/docs)
- [Supabase (PostgreSQL)](https://supabase.com/docs)
- [Tailwind CSS](https://tailwindcss.com/docs/installation/using-vite)
